## 决策规则

| 当… | 用… |
|---|---|
| 实力不足、时机未到 | 潜龙勿用，积蓄待时（乾初九） |
| 势头正盛、身居高位 | 亢龙有悔，戒骄收敛（乾上九） |
| 太平日久、疏忽守成 | 城复于隍，居安思危（泰上六） |
| 身处乱世、小人当道 | 俭德辟难，韬光养晦（否卦） |
| 遭遇挫折、身处低谷 | 艰贞无咎，否极泰来（否九四/上九） |
| 需要推动变革 | 革故鼎新，顺天应人（革、鼎） |
| 与人协作、有所成就 | 谦逊受益，功成不居（谦卦） |
| 事情即将完成 | 思患预防，以未济心态再出发（既济/未济） |

## 主题卦象速查

- **进取/退守**：乾（进）、坤（顺）、遁（退）、大壮（强）
- **通塞盛衰**：泰、否、剥、复
- **处世之德**：谦、巽、节、中孚
- **变革更新**：蛊、革、鼎
- **险困自守**：坎、困、井、蹇、明夷
- **始终循环**：既济、未济
