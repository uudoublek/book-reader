# Glossary — 核心术语

- **易（Yi）** — 含"简易、变易、不易"三义：大道至简、万物恒变、变中有常。
- **阴阳（Yin-Yang）** — 解释万物的两大基本范畴：乾为纯阳、坤为纯阴，阴阳交感而生万物，互相依存、互相转化。
- **太极（Taiji）** — 阴阳未分的混沌本原；"太极生两仪，两仪生四象，四象生八卦"。
- **两仪 / 四象 / 八卦** — 阴阳为两仪；太阳、太阴、少阳、少阴为四象；四象再各生阴阳为八卦。
- **八卦（Bagua）** — 乾☰天、兑☱泽、离☲火、震☳雷、巽☴风、坎☵水、艮☶山、坤☷地。
- **六十四卦（64 Hexagrams）** — 八卦两两相重而成，每卦六爻；上经 30 卦、下经 34 卦。
- **卦辞** — 每卦开头的总断语，断一卦吉凶（如乾"元亨利贞"）。
- **爻辞** — 每爻的断语，分断六爻时位吉凶（如乾初九"潜龙勿用"）。
- **彖传** — 解释卦辞的传文（"彖曰"），阐发一卦的哲理。
- **象传** — 由卦象/爻象引申到人事修养的传文（"象曰"），分大象（论卦）与小象（论爻）。
- **元亨利贞** — 乾卦四德：元始、亨通、和谐有利、正固持久；亦为事物发展的四阶段。
- **上经 / 下经** — 上经（1–30）讲天道创世，下经（31–64）讲人伦持守。
- **祖卦** — 乾坤二卦，为六十四卦之根本。
- **六爻（Liu Yao）** — 每卦六画，自下而上称初爻、二爻、三爻、四爻、五爻、上爻。
- **九 / 六** — 爻题中"九"表阳爻、"六"表阴爻；"初九""九二""上六"等由爻位与阴阳组成。
- **当位 / 正** — 阳爻居阳位（初、三、五）、阴爻居阴位（二、四、上）为"当位/正"，反之为"不当位"。
- **中（Zhong）** — 二、五爻居上下卦之中，为"中"，最吉；"中道"是《易经》的核心理想。
- **应 / 比** — 上下卦同位之爻（初与四、二与五、三与上）相感为"应"；相邻之爻相比为"比"。
- **时（Shi）** — 所处的大势与时机；"得时则行，失时则止"。
- **贞（Zhen）** — 守正、正固；"利贞"即利于守正。
- **悔 / 吝 / 咎 / 凶** — 爻辞断语，由轻微之悔到较重之咎、至最重之凶，程度递进。
- **潜龙勿用 / 飞龙在天 / 亢龙有悔** — 乾卦六爻取龙为象的三个关键：潜藏待时、得势而飞、过亢而悔。
- **自强不息 / 厚德载物** — 乾《象》"天行健，君子以自强不息"；坤《象》"地势坤，君子以厚德载物"。
- **物极必反** — "无平不陂，无往不复"（泰九三）；泰极而否、否极泰来、剥极而复。
- **三易** — 《连山》《归藏》《周易》合称三易；今传世者为《周易》。
- **十翼** — 《彖》《象》《文言》《系辞》《说卦》《序卦》《杂卦》等解释《易经》的传文，相传孔子所作。
