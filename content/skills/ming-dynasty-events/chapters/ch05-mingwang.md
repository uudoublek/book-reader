# 柒 大结局 — 崇祯与明朝灭亡

## Core Idea
第七部是全书的终章，讲明朝的覆亡。崇祯帝朱由检勤政节俭、力图振作，却刚愎多疑、滥杀大臣（冤杀袁崇焕），在内外交困中越用力越加速崩溃。李自成农民军席卷北方、攻破北京；崇祯自缢煤山，留下"诸臣误我"的遗恨；随后吴三桂引清军入关，满清入主中原。作者的核心判断：**明朝之亡不是一人一事之罪，而是两百多年制度积弊的总爆发——气数已尽，非人力可挽**。

## 各篇要义

### 朱由校篇（天启，接续）
天启后期魏忠贤专权达于极盛，但阉党内部也矛盾重重；明军与后金在辽东反复争夺，宁远之战中袁崇焕炮伤努尔哈赤，取得一时胜利。天启帝早逝，无嗣。

### 朱由检篇（崇祯）
- **勤政与刚愎**：崇祯帝即位后铲除魏忠贤，勤于政事、厉行节俭，欲挽狂澜；但生性多疑、急于求成，在位十七年换了数十位内阁首辅，滥杀大臣。
- **袁崇焕之冤**：袁崇焕"五年平辽"的豪言未能兑现，又因擅杀毛文龙、后金反间计等，被崇祯凌迟处死——"自毁长城"。
- **内外交困**：关外皇太极（后金/清）不断进逼，五次入塞；关内李自成、张献忠起义军日益壮大，流动作战、攻州破府。
- **甲申之变（1644）**：李自成攻破北京，崇祯自缢于煤山，留下"朕非亡国之君，诸臣皆亡国之臣"的悲鸣，明朝灭亡。
- **清军入关**：吴三桂引清军入关，联合击败李自成；满清入主中原，开启清朝。
- **遗民与气节**：史可法扬州抗清、郑成功收复台湾等，是明亡之后不绝的"气节"余响。

## Key Takeaways
1. 崇祯"勤政却亡国"是全书最深的悲剧：方向错了，越努力越糟。
2. 冤杀袁崇焕是"自毁长城"——猜忌多疑比外敌更致命。
3. 明朝之亡是制度性崩溃：宦官、党争、财政、边患、民变交织成死结。
4. "气数已尽"背后是两百多年的积弊，非一人之力可挽。
5. 明亡之后，气节（史可法、郑成功）仍在，历史的精神火种未熄。
