# 贰 万国来朝 — 朱棣到朱祁钰

## Core Idea
第二部讲明代的鼎盛与第一次重大转折。朱棣夺位后迁都北京、派郑和七下西洋、修《永乐大典》，缔造"永乐盛世"，又以空前功业洗刷篡位之名。其后仁宗、宣宗延续"仁宣之治"，国力臻于顶峰。然而转折点在明英宗朱祁镇：宦官王振擅权，酿成"土木堡之变"（皇帝被俘），幸赖于谦力挽狂澜、打赢北京保卫战，明朝才免于覆亡。这一部完成了"盛世"与"危机"的双重书写。

## 各篇要义

### 朱棣篇（永乐）
- **篡位与合法性焦虑**：以"靖难"夺侄帝位，为消弭篡位之名而励精图治、大兴功业。
- **迁都北京**：将都城由南京迁至北京，天子守国门，奠定后世格局。
- **郑和下西洋**：派郑和率庞大舰队七下西洋，宣扬国威、万国来朝，展现空前国力（亦暗含寻访建文帝的动机）。
- **修《永乐大典》**：编修旷世巨著，彰显文治。

### 朱高炽篇（洪熙）与朱瞻基篇（宣德）
- **仁宣之治**：仁宗、宣宗宽仁守成、休养生息，与民更始，被誉为明代治世典范；宣德年间设"票拟""批红"，内阁与司礼监权力渐起。

### 朱祁镇篇（正统）与朱祁钰篇（景泰）
- **王振擅权**：明英宗朱祁镇宠信宦官王振，朝政渐坏。
- **土木堡之变（1449）**：王振怂恿英宗御驾亲征瓦剌，兵败土木堡，英宗被俘，二十万大军覆没，明朝遭遇开国以来最大危机。
- **于谦与北京保卫战**：于谦力排南迁之议，拥立景帝朱祁钰，组织北京保卫战，击退瓦剌（也先），力挽狂澜。"粉身碎骨浑不怕，要留清白在人间"是其气节写照。

## Key Takeaways
1. 永乐盛世是"篡位者"用功业洗白自己的结果——合法性焦虑反而催生了辉煌。
2. 郑和下西洋是明代国力的巅峰，也是中国海权的一次耀眼亮相。
3. 仁宣之治是守成之君"宽仁养民"的典范。
4. 土木堡之变是转折点：宦官干政的恶果首次以"皇帝被俘"的极端形式爆发。
5. 于谦的"气节"是全书的道德高地：危难之际，一人撑起一个王朝。
