# 伍 帝国飘摇 + 陆 日暮西山 — 隆庆到天启

## Core Idea
第五、六部讲明代由"中兴"滑向"衰亡"的过程。隆庆朝短暂开放海禁（"隆庆开关"）；万历初年张居正推行"一条鞭法"等改革，创"万历中兴"，但死后遭清算、家破人亡；万历帝此后数十年不上朝，朝政糜烂、党争四起。明光宗"红丸案"暴死，明熹宗天启年间魏忠贤阉党乱政，东林党人遭残酷迫害。这一部分揭示：**明代政治的病灶已深入骨髓，中兴只是回光返照，衰亡的齿轮已经启动**。

## 各篇要义

### 伍 帝国飘摇（朱厚熜～朱翊钧）
- **朱载垕（隆庆）**：短暂在位，开放海禁（"隆庆开关"）、与蒙古俺答和议（"隆庆和议"），为万历奠定基础。
- **张居正改革**：万历初年，张居正任内阁首辅，推行"一条鞭法"（赋役合并、折银征收）、考成法整顿吏治、清丈田亩，国力回升，创"万历中兴"。
- **张居正身后清算**：张居正死后遭万历帝清算，抄家、削夺、子孙流放——能臣的功业与身家的毁灭同源，是明代政治"反噬"的典型。
- **万历怠政**：万历帝（朱翊钧）因"国本之争"（立太子）与文官集团对抗，数十年不上朝，朝政空转、党争加剧。

### 陆 日暮西山（朱翊钧～朱由校）
- **朱常洛（泰昌）**：即位一月即暴死（"红丸案"），是明代最短命的皇帝。
- **东林党与党争**：东林书院讲学议政，形成"东林党"；与浙党、楚党及后来的阉党互相倾轧，党争成为晚明政治的主题。
- **朱由校（天启）与魏忠贤阉党**：天启帝荒嬉木工，宠信宦官魏忠贤。魏忠贤结"阉党"、权倾朝野，迫害东林党人（"六君子""七君子"之狱），厂卫横行，政治极度黑暗。
- **危机四伏**：关外后金（努尔哈赤）崛起、辽东告急，关内民变渐起，明王朝风雨飘摇。

## Key Takeaways
1. 张居正改革是明代最后一次中兴机会，但"人亡政息"——改革者被清算，改革随之废止。
2. 万历怠政与"国本之争"暴露了皇权与文官集团的僵局：皇帝以"不上朝"消极对抗。
3. 党争（东林/阉党）把国家大事让位于门户之见，是晚明政治的自毁。
4. 魏忠贤阉党是明代宦官专权的顶点，也是政治黑暗的极致。
5. "帝国飘摇→日暮西山"的递进说明：明朝的衰亡是制度性的、不可逆的。
