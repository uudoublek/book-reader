# Glossary — 核心术语

- **靖难之役** — 燕王朱棣以"清君侧"为名发动的夺位战争，夺侄子建文帝帝位。
- **永乐盛世** — 明成祖朱棣时期的鼎盛局面（迁都北京、郑和下西洋、修《永乐大典》）。
- **郑和下西洋** — 明成祖派郑和率舰队七下西洋的远航壮举，宣扬国威。
- **仁宣之治** — 仁宗、宣宗时期宽仁守成的治世。
- **土木堡之变** — 1449 年明英宗亲征瓦剌兵败被俘的惨败，明朝由盛转衰的转折点。
- **北京保卫战** — 于谦组织军民击退瓦剌、保卫北京的战役，力挽狂澜。
- **夺门之变** — 1457 年英宗朱祁镇复辟的政变，于谦被冤杀。
- **大礼议** — 嘉靖帝为尊生父兴献王为"皇考"与群臣的政治斗争。
- **知行合一** — 王阳明心学核心命题：知与行不可分，须在"事上磨练"。
- **致良知** — 王阳明心学：体认、扩充内心本有的良知。
- **一条鞭法** — 张居正推行的赋役改革：赋役合并、折银征收。
- **考成法** — 张居正整顿吏治的考核制度。
- **隆庆开关** — 隆庆朝开放海禁，允许民间海外贸易。
- **国本之争** — 万历朝围绕立太子的长期政治斗争。
- **红丸案** — 泰昌帝服用"红丸"暴死的疑案（明末三大案之一）。
- **东林党** — 以东林书院为中心的士大夫清流集团，与阉党对立。
- **阉党** — 依附宦官魏忠贤的政治集团。
- **厂卫** — 东厂、西厂、锦衣卫等特务机构。
- **锦衣卫** — 明太祖设立的特务机构，后成为明代政治的重要力量。
- **一条鞭法 / 内阁 / 司礼监** — 赋役制度 / 中枢议政机构 / 宦官掌批红的机构，构成明代权力格局。
- **票拟 / 批红** — 内阁草拟意见（票拟）与皇帝（或司礼监代行）批答（批红）的政务流程。
- **后金 / 清** — 努尔哈赤建立的后金政权，后改国号"清"。
- **甲申之变** — 1644 年李自成破北京、崇祯自缢、明朝灭亡的变局。
- **气节** — 全书反复咏叹的道德主题：忠臣义士的坚守与清白。
