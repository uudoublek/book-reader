## 关键事件时间线

```
1368 朱元璋称帝建明 → 1399 靖难之役 → 1402 朱棣夺位 → 1405 郑和下西洋
→ 1449 土木堡之变 + 北京保卫战 → 1457 夺门之变 → 1519 王阳明平宁王
→ 1521 嘉靖大礼议 → 1567 隆庆开关 → 1573 张居正改革 → 1582 张居正去世被清算
→ 1619 萨尔浒之战(后金崛起) → 1627 魏忠贤专权 → 1644 甲申之变(明亡)
```

## 决策规则（历史教训）

| 当… | 警示… |
|---|---|
| 得位不正、急于证明自己 | 可能靠功业洗白，也易走向穷兵黩武 |
| 改革触动既得利益 | 须防"人亡政息"、身后反噬（张居正） |
| 皇帝荒嬉/怠政 | 权柄必旁落宦官权臣（王振/魏忠贤） |
| 党争门户之争 | 国家大事让位于派系，是自毁 |
| 勤政但猜忌滥杀 | 方向错，越努力越亡（崇祯、袁崇焕） |
| 制度多系统同时失效 | 是系统性崩溃，非一人一事之罪 |

## 一句话总纲

明朝 276 年、16 帝：以朱元璋的极权开国，以永乐的空前功业达于鼎盛，在宦官、党争、财政、边患的交织中一路滑向深渊，最终崇祯煤山自缢——而"气节"二字，是这出三百年大戏里最亮也最痛的精神底色。
