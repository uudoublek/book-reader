# Chapter 4: The Changing Value of Money（货币价值的变化）

## Core Idea
所有货币最终都会贬值或死亡——自 1700 年以来约 750 种货币仅约 20% 存续，且全部经历过贬值；大贬值是"abrupt and episodic"（突然、偶发）而非常态演进。货币价值由金融经济的供需决定，衡量标尺是它相对债务、黄金、商品服务（CPI）与股票的表现。

## Frameworks Introduced
- **Six devaluations（过去 170 年六次主要货币大贬值）**。When to use：给当前货币风险定位。How：按时间框架核对——1860s 美国内战暂停金兑换印"greenbacks"；1870s 各国加入金本位（日本银本位、西班牙频繁暂停可兑换性为例外）；WWI 战争赤字→1919-22 战败国印钞贬值（德国马克 1920-23 崩盘）；1920s 繁荣泡沫→1929 破裂→1930s 全球印钞与竞争性贬值→二战；1944-45 布雷顿森林（美元挂金、各国挂美元），战败国货币彻底摧毁、战胜国大幅贬值；1968-73（最重要 1971）美元脱金；2000 以来自由浮动体系下的渐进持续贬值。
- **货币贬值的四个衡量标尺**：against debt（印钞目标即减轻债务负担）、against gold（黄金是 timeless and universal 的替代货币）、against CPI basket（购买力）、against stocks。When to use：评估贬值幅度与性质。How：四者同向时贬值"足够大"。
- **Devaluing vs losing reserve currency status（贬值 ≠ 丧失储备货币地位）**。When to use：判断某货币危机是否会升级为体系性事件。How：核对共同模式——经典的 "run" 动态（对央行的债权超过可用硬通货）；央行净储备在贬值前数年即开始下降（英国 1947 前、1949 贬值前；美国 1971）；常伴随战时债务（荷兰第四次英荷战争、英国两次世界大战、美国越战）；央行先加息随即"capitulate"印钞再降息；结局取决于贬值时该国剩余的经济军事实力（荷兰崩溃迅速，英国两次贬值后渐进失去地位，美国两次大贬值仍保住地位）。
- **MP1 / MP2（Monetary Policy 1：利率调节资本分配；Monetary Policy 2：印钞购买优质债务）**。When to use：识别政策工具箱耗尽信号。How：两者失灵时货币政策沦为政治系统分配资源（uneconomic allocation）的工具；需区分 systemically beneficial devaluations 与 systemically destructive ones。

## Key Concepts
| 术语 | 中文 |
| --- | --- |
| Devaluation / debasement | 贬值（印钞使货币与债务价值下降） |
| Real interest rates | 实际利率（名义利率−通胀率） |
| Inflation-hedge assets | 通胀对冲资产（黄金、大宗商品、通胀挂钩债券、其他货币含数字币） |
| Real stock prices | 实际股价（调整通胀后）——债务减免流入生产力时上升 |
| Run on the currency | 对货币的挤兑（债权>硬通货） |
| Reserve currency status | 储备货币地位 |
| Hyperinflation | 恶性通胀（魏玛德国为历史之最） |
| Bretton Woods | 布雷顿森林体系（1944-45 建立，1971 终止） |

## Mental Models
- 当评估持有现金/政府票据的长期回报时，用"1850 年至今 bills vs gold 实际回报"的历史数据：1912 年（现代法币时代）以来 bills 平均实际回报 −0.1%，gold 为 +1.6%。
- 当判断一国货币是否濒临崩溃时，用储备货币衰落模式清单：净储备下降→暂停可兑换性→run→先加息后屈服印钞。
- 当区分贬值好坏时，用 systemically beneficial vs destructive：前者让债务减免流向生产力与利润→实际股价升；后者损害信贷配置体系，但常为建立新货币秩序所必需（"needed to wipe out debt"）。
- 当评估"逃离货币"的资产去向时，记住无需替代储备货币也会发生（王朝中国、罗马帝国；魏玛德国人逃向岩石、黄金、实物股票）。

## Anti-patterns
1. 只担心资产涨跌，几乎不关注本币价值（"you are not nearly as aware of your currency risk as you need to be"）。
2. 视"cash 为最安全资产"——所有货币都贬值或消亡，cash 与 bonds（收取货币的承诺）随之被贬值或抹掉。
3. 假设必须有替代储备货币才会发生挤兑逃离——历史上无替代货币时同样崩溃。
4. 把可兑换承诺当永久：1933 与 1971 两次美元脱金都"让大多数人惊讶"——机制明白人不惊讶。
5. 忽视大贬值的突发性：六次大贬值均为 episodic 事件而非渐进曲线；自 2000 年起的渐进贬值是自由浮动体系下的新形态，非常态。
6. 持有票据时只看名义利息——约半数国家为负实际回报（法国、意大利、日本年损失超 2%，德国因恶性通胀年损失超 18%）。

## Worked Example
书中数据表（vs CPI 实际年回报）：1850–Present 持有政府票据 vs 黄金——US 1.6% vs 0.3%，UK 1.4% vs 0.7%，Germany −12.9% vs 2.0%（德国被"彻底抹掉"两次：魏玛恶性通胀与二战）。分时代看：1850–1912（金本位繁荣期）平均 bills +3.6%、gold −0.3%；1912 至今 bills −0.1%、gold +1.6%。案例：英国 1947 年暂停可兑换性、1949 年贬值——持有英镑者因政治压力继续持有，同期资产表现显著劣于美国资产；最终两次贬值后布雷顿森林体系期间失去储备货币地位。

## Key Takeaways
- 把 currency risk 纳入资产配置：长期视角下现金 vs 黄金/通胀对冲资产的回报分化是结构性的（法币时代 gold +1.6%/年 vs bills −0.1%/年）。
- 贬值最重要对象是 debt：印钞目标即减负；观察新货币流向——流入生产力则实际股价升，流入通胀对冲资产则货币价值自我强化下跌。
- 盯住经典前兆：央行净储备下降、债权 vs 硬通货比例、战时/大规模赤字背景、央行"先加息后屈服"。
- 储备货币地位的丧失是慢性贬值与权力转移（对崛起对手失去经济政治首要地位）共同作用的产物——荷兰→英国→美国的历史会重演。
- 明确区分"贬值"与"丧失储备地位"：美国 1933、1971 两次大贬值未失地位，因其仍保有经济军事实力。
