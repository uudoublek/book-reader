# Cheatsheet — 决策规则速查

## 定位决策树：判断一国在大周期中的位置

```
先看三大周期（债务/内部/外部）同向性 → 不同向则看多数方向
  ↓
看 8 项权力：教育/竞争力先升先衰（领先），储备货币/金融中心后升后降（滞后）
  ↓
对照 5 阶段心理周期：穷而自知(上升) → 富而自认穷(最有成效) → 富而自认富(高峰)
  → 穷而自认富(早期衰落) → 穷而自知(衰退)
  ↓
对照内部秩序 6 阶段：1新秩序 2资源分配 3繁荣 4过度/泡沫 5财政恶化+冲突 6内战/革命
```

## 决策规则

| 当看到… | 做… | 因为… |
| --- | --- | --- |
| 巨额债务 + 零利率 + 央行大印钞 | 预期贬值路径，配置通胀对冲资产 | 长期债务周期 Stage 4-5 的既定剧本 |
| 利率打到 0% 仍不够 | 预期 MP1→MP2→MP3 递进 | 央行工具箱耗尽顺序固定 |
| 央行净储备持续下降 | 进入货币贬值预警 | 贬值前数年即开始（英国 1947/1949、美国 1971） |
| 债务+巨大贫富差距+负面冲击三齐 | 高风险区，考虑撤离 | Classic Toxic Mix 触发内战/革命 |
| 经济红旗 >80% | 严重内部冲突概率 ~1/3 | 29 次内战历史统计 |
| 领先指标（教育/竞争力）先衰 | 早期预警，别被汇率迷惑 | 储备货币是滞后指标，最后才倒 |
| 金融财富/实体财富比极高 + 实际利率近零 | 现金债券实际回报差，考虑抗通胀资产 | 美国名义回收期 ~45 年、实际不可收回 |
| 民粹极化 + 媒体信任度暴跌 | Stage 5 标志，准备两种剧本 | 盖洛普：72%(1976)→13%(2019) |
| 两国军事相当 + 存在性分歧 | 战争风险最高，盯红线 | 台湾问题类比 |
| 经济战出现（关税/禁运） | 预期 10 年内可能军事升级 | "Before a shooting war, an economic war" |
| 对手时间站在他那边 | 对方倾向拖延，我方需明确加速/缓和意图 | 中国想晚打、美国想早打 |
| 权力相对下降时 | 趁权力最大时尽早协议或行动 | 拖延到被动挨打更糟 |
| 危机应对预测 | 预期最终印钞贬值（四杠杆终局） | 最政治可接受、最不透明 |
| 盛世繁荣 + 低负债 + 小差距 | 最好的建设窗口，而非乐观理由 | 繁荣期播下衰落种子 |

## 阈值与默认值

- 和平/创造期 vs 萧条/革命/战争期 ≈ **5:1**（长期债务周期 ~50-75 年，商业周期 ~8 年）
- 内部秩序大周期 ≈ **100 年**；王朝周期 ≈ **250 年（±150）**；三代 ≈ 一个长期债务周期
- 红旗指数：**60-80%** → ~1/6 内战概率；**>80%** → ~1/3
- 法币时代（1912 起）：bills 平均实际回报 **-0.1%**/年 vs gold **+1.6%**/年
- 1900 十大强国投资：**10 国中 7 国**财富至少一次近清零
- 美国大周期完成度：**~70%（±10%）**，处于 Stage 5（作者 2021 判断）
- 中国：人均 GDP 2018 = 1978 的 **25 倍**；贫困率 96% → 1%；2030 前经济规模或超美（作者预测）
- 下一次衰退估计：本书出版后 ~4 年（±几年），距 2020 年 4 月底部 ~5.5 年

## Tells & Smells（快速识别信号）

- **"it won't happen here"** — 长期和平后最常见的自满信号，内战不可避免应准备
- **"looks rich but going broke"** — 收入<支出+资产>负债的实体：损益表问题终将传导到资产负债表
- **媒体信任度骤降 + 党派极化** — Stage 5 内部冲突加剧的标志
- **资本外逃**（储蓄者买崛起国资产）— 衰落国命运已定（荷兰资金流向英国先例）
- **"聪明的兔子有三个洞"** — 多样化不足时听到的自我安慰，实际风险敞口过大
- **炫耀权力** — 引发对方恐惧与反制，导致互相升级；藏刀式权力更有效
- **政策"先加息后屈服"** — 央行 capitulate 印钞的经典前奏
- **战时高税率**（美国 94%、英国 98%）— 战争冲击资产配置的极端信号
