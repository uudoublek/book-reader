## 决策规则

| 当… | 用… |
|---|---|
| 要判断形势、做重大判断 | 看实质而非现象，先调查再发言 |
| 头绪多、资源少、要定优先级 | 抓主要矛盾，弹钢琴统筹 |
| 面对强敌、实力悬殊 | 战略藐视、战术重视；集中优势兵力各个击破 |
| 力量弱小、前景不明 | 星星之火可以燎原，看发展的必然性 |
| 推动群众、发动群众 | 从群众中来、到群众中去，反对命令主义与尾巴主义 |
| 与合作者打交道、有分歧 | 有理、有利、有节，既统一又独立 |
| 批评同志、处理内部错误 | 惩前毖后、治病救人，团结—批评—团结 |
| 取得成绩、身居顺境 | 两个务必，警惕糖衣炮弹，戒骄戒躁 |
| 带班子、做决策 | 党委会工作方法：摆到桌面、互通情报、胸中有数 |

## 四卷脉络速查

- **第一卷（1925–1937）**：分清敌友 → 找到农民 → 农村割据 → 思想方法 → 《实践论》《矛盾论》哲学总结。
- **第二卷（1937–1941）**：持久战 + 游击战战略 → 统一战线独立自主 → 三大法宝 → 新民主主义论。
- **第三卷（1941–1945）**：延安整风（实事求是）→ 三大作风 → 为人民服务 → 论联合政府规划建国。
- **第四卷（1945–1949）**：纸老虎 → 十大军事原则 → 两个务必 → 人民民主专政立国。

## 三大法宝与三大作风

| 三大法宝 | 定位 |
|---|---|
| 统一战线 | 团结多数、孤立敌人的基本武器 |
| 武装斗争 | 革命的主要斗争形式 |
| 党的建设 | 掌握两大武器的"战士" |

| 三大作风 | 内涵 |
|---|---|
| 理论联系实际 | 实事求是、有的放矢 |
| 密切联系群众 | 全心全意为人民服务 |
| 批评与自我批评 | 坚持真理、修正错误 |
