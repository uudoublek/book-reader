# 第二卷 — 抗日战争时期·上（1937–1941）

## Core Idea
第二卷覆盖抗战前期（1937–1941），是毛泽东思想走向成熟、系统化的时期。三条主线：**（1）军事上**提出持久战与游击战战略，驳倒"亡国论"与"速胜论"；**（2）政治上**完善抗日民族统一战线，坚持"独立自主"；**（3）理论上**在《中国革命和中国共产党》《新民主主义论》中系统阐述中国革命的性质、对象、动力与前途，形成完整的新民主主义革命理论。

## 各篇要义

### 反对自由主义（1937）
列举自由主义十一种表现（如"事不关己，高高挂起""当面不说，背后乱说"），指出它"取消思想斗争，主张无原则的和平"，是"小资产阶级的自私自利性"。号召"用以马克思主义的积极精神，克服消极的自由主义"。

### 抗日游击战争的战略问题（1938）
论证游击战在中国抗日中不只是战术问题、更是战略问题。六条具体战略问题：主动灵活地执行防御中的进攻、持久中的速决、内线中的外线；与正规战争配合；建立根据地；战略防御与进攻；向运动战发展；指挥关系。总方针是"保存自己，消灭敌人"。

### 论持久战（1938）
抗战时期最重要的军事政治著作。核心论断：抗日战争是持久战，最后胜利属于中国。批判"亡国论"（只看到敌强我弱）与"速胜论"（只看到我有正义与大国）。提出三阶段：战略防御 → 战略相持 → 战略反攻。"战争的伟力之最深厚的根源，存在于民众之中"；"兵民是胜利之本"。强调主观能动性须建立在客观物质条件之上。

### 统一战线中的独立自主问题（1938）
批判王明右倾"一切经过统一战线""一切服从统一战线"。主张"既统一，又独立"——在统一战线中保持共产党在思想上、政治上、组织上的独立性，坚持"民族斗争和阶级斗争的一致性"。

### 战争和战略问题（1938）
"枪杆子里面出政权"的名言出处。"我们的原则是党指挥枪，而决不容许枪指挥党。"系统总结中国革命的特点：武装斗争是主要斗争形式，军队是主要组织形式。

### 《共产党人》发刊词（1939）
提出中国革命胜利的**三大法宝**："统一战线，武装斗争，党的建设"。三者关系：统一战线与武装斗争是战胜敌人的两个基本武器，而党的组织是掌握这两个武器的战士。

### 中国革命和中国共产党（1939）
教科书式的国情分析：中国是"半殖民地、半封建社会"；革命对象是帝国主义、封建主义、官僚资本主义；动力是工人、农民、小资产阶级、民族资产阶级；性质是新民主主义革命，前途是社会主义。

### 纪念白求恩（1939）
赞扬加拿大医生白求恩"毫不利己专门利人"的精神，提炼出"对工作的极端的负责任，对同志对人民的极端的热忱"的标杆。提出做"一个高尚的人，一个纯粹的人，一个有道德的人，一个脱离了低级趣味的人，一个有益于人民的人"。

### 新民主主义论（1940）
系统阐述新民主主义革命的政治、经济、文化纲领：政治上建立"各革命阶级联合专政"的民主共和国；经济上没收官僚资本、节制资本、耕者有其田；文化上发展"民族的、科学的、大众的"新文化。提出革命分"两步走"：新民主主义革命是社会主义革命的必要准备。

### 目前抗日统一战线中的策略问题（1940）
提出统一战线中"发展进步势力，争取中间势力，孤立顽固势力"的策略总方针，以及同顽固派斗争的"有理、有利、有节"三原则。

### 论政策（1940）
综合论述抗日民族统一战线的各项政策，强调"在区别上建立我们的政策"——没有区别就没有政策，反对"左"的与右的两种偏向。

## Key Takeaways
1. "兵民是胜利之本"——持久战与游击战的根基都在发动群众。
2. 统一战线要"既统一又独立"，在合作中保持原则与自主。
3. 三大法宝（统一战线、武装斗争、党的建设）是革命胜利的总钥匙。
4. 《新民主主义论》把革命的性质、对象、动力、前途讲透，是建国理论的基础。
5. "枪杆子里面出政权"与"党指挥枪"——武装斗争与政治领导须统一。
