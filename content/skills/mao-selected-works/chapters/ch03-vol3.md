# 第三卷 — 抗日战争时期·下（1941–1945）

## Core Idea
第三卷覆盖抗战后期（1941–1945），主题是**在艰苦的相持阶段中整顿自身、统一思想，为胜利与建国做准备**。核心是延安整风（反对主观主义、宗派主义、党八股）与确立"实事求是"的思想路线；同时在经济、文化、政权建设上提出系统方针，最终以《论联合政府》规划战后建国蓝图。这一卷讲的是"如何把党建设得更加成熟、如何赢得民心"。

## 各篇要义

### 改造我们的学习（1941）
延安整风的纲领性文献，给"实事求是"下经典定义："'实事'就是客观存在着的一切事物，'是'就是客观事物的内部联系，即规律性，'求'就是我们去研究。"批判主观主义学风（"无实事求是之意，有哗众取宠之心"），提出"有的放矢"——用马克思主义之"矢"射中国革命之"的"。

### 整顿党的作风（1942）
提出整风三大任务：反对主观主义以整顿学风，反对宗派主义以整顿党风，反对党八股以整顿文风。"主观主义是共产党的大敌……是党性不纯的一种表现。"方针是"惩前毖后，治病救人"。

### 反对党八股（1942）
历数党八股"八大罪状"：空话连篇、装腔作势、无的放矢、语言无味、甲乙丙丁开中药铺（形式主义罗列）、不负责任、流毒全党、妨害革命。强调"共产党不靠吓人吃饭，而是靠马克思列宁主义的真理吃饭，靠实事求是吃饭"。

### 在延安文艺座谈会上的讲话（1942）
文艺工作的纲领：文艺必须"为工农兵服务""为人民大众服务"，普及与提高相结合，文艺工作者要深入生活、改造世界观。确立了"文艺为人民服务、为社会主义服务"的方向。

### 关于领导方法的若干问题（1943）
提出"从群众中来，到群众中去"的领导方法，和"一般和个别相结合""领导和群众相结合"两条原则。指出"任何有群众的地方，大致都有比较积极的、中间状态的和比较落后的三部分人"，领导要善于团结积极分子、带动中间、帮助落后。

### 为人民服务（1944）
为悼念张思德作。核心："我们这个队伍完全是为着解放人民的，是彻底地为人民的利益工作的。""人固有一死，或重于泰山，或轻于鸿毛。为人民利益而死，就比泰山还重。"

### 论联合政府（1945，中共七大政治报告）
系统阐述抗战胜利后的建国纲领：废除国民党一党专政，建立民主的联合政府。提出党的二十大作风——"理论和实践相结合的作风，和人民群众紧密地联系在一起的作风，以及自我批评的作风"。重申"全心全意为人民服务，一刻也不脱离群众"。

### 愚公移山（1945，七大闭幕词）
以"愚公移山"寓言号召："下定决心，不怕牺牲，排除万难，去争取胜利。"指出要感动"上帝"（人民大众）来一起挖掉帝国主义、封建主义两座大山。

### 学习和时局（1944）
总结历史经验，强调"放下包袱，开动机器"——去掉思想负担、善于思考；"凡事应该用脑筋好好想一想"，克服盲目性。

## Key Takeaways
1. 延安整风确立"实事求是"为思想路线，是党走向成熟的关键一环。
2. 三大作风（理论联系实际、密切联系群众、批评与自我批评）是党的立身之本。
3. 整风方针是"惩前毖后、治病救人"——对事不对人、团结—批评—团结。
4. "为人民服务"把宗旨讲到底：以人民利益为最高标准。
5. 领导方法的核心是"从群众中来，到群众中去"，反对命令主义与尾巴主义。
