## 核心断言速查

| 问题 | 柏拉图的主张 |
|---|---|
| 什么是正义？ | 灵魂/城邦各司其职的内在和谐（非强权、非名声） |
| 谁该统治？ | 哲人王——权力与智慧合一 |
| 什么是知识？ | 对永恒理念（Form）的把握，非感官意见 |
| 教育是什么？ | 灵魂的转向（periagoge），非灌输 |
| 政体为何衰败？ | 随灵魂（欲望结构）堕落而衰变 |
| 正义有何回报？ | 在正义本身（灵魂和谐即幸福）+ 厄洛斯神话的终极奖惩 |
| 艺术该不该存在？ | 模仿是"影子的影子"，须以善为标准审查，极端处驱逐诗人 |

## 灵魂三分与城邦对应

| 灵魂部分 | 德性 | 对应阶层 |
|---|---|---|
| 理性（爱智） | 智慧 | 统治者 |
| 激情（意气） | 勇敢 | 护卫者/军人 |
| 欲望 | 节制 | 生产者 |

## 政体衰变链（第八卷）

```
荣誉政治（好胜者）→ 寡头政治（贪财者）→ 民主政治（放纵者）→ 僭主政治（欲望奴隶）
```

## 教育阶梯（第七卷）

```
音乐+体育（调谐激情理性）→ 算术/几何/天文/谐音（数理）→ 辩证法（第一原理）→ 下洞从政
```
