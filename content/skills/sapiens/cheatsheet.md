# Cheatsheet — 框架速查

## 四大革命时间线

| 革命 | 时间 | 关键变化 |
|---|---|---|
| 认知革命 | 约 7 万年前 | 语言能讨论不存在的事物→虚构故事→大规模合作 |
| 农业革命 | 约 1.2 万年前 | 小麦"驯化"智人；食物总量↑但人均更差 |
| 科学革命 | 约 500 年前 | 承认无知→观察+数学→新能力 |
| 智人末日（进行中） | 当下 | 智慧设计取代自然选择 |

## 核心断言速查

| 问题 | 赫拉利的主张 |
|---|---|
| 智人为何统治世界？ | 虚构故事的能力（共同想象→大规模合作） |
| 农业革命是进步吗？ | 史上最大骗局——演化成功≠个体幸福 |
| 阶级有生物学基础吗？ | 没有——历史偶然+虚构+恶性循环 |
| 金钱/国家是什么？ | 主体间现实（集体想象） |
| 科学革命的本质？ | 无知革命——承认无知 |
| 资本主义的核心？ | 信用=对未来的信任 |
| 幸福由什么决定？ | 生化机制+期望（非财富） |
| 人类的未来？ | 生物工程/仿生工程/无机生命 |

## 三大全球秩序

```
金钱（最成功的互信系统）+ 帝国（同化循环"他们变我们"）+ 宗教（给想象秩序超人类合法性）
→ 三者合力推动人类走向"分久必合"的全球单一文化
```

## 三种现实

| 类型 | 例子 | 特征 |
|---|---|---|
| 客观 | 放射线 | 不因人而异 |
| 主观 | 想象的朋友 | 只对个人真实 |
| 主体间 | 法律、金钱、神 | 需千万人共同相信 |

## 幸福双因子

```
快乐 ≈ 生化机制（血清素/多巴胺/催产素的恒温设定）+ 期望与现实的相符度
```

## 智人末日三途径（第 20 章）

```
生物工程（基因改造、尼安德特人复活）
仿生工程（生化人 cyborg）
无机生命（AI、奇异点 singularity）
→ 真正的问题不是"想变成什么"，而是"究竟希望自己想要什么"
```

## 关键名言

- "智人统治世界，靠的是能讨论根本不存在的事物。"
- "不是人类驯化了小麦，而是小麦驯化了智人。"
- "天生带来允许，文化造成封闭。"
- "发现人类对最重要的问题一无所知，是最伟大的发现。"
- "历史从无正义，但我们可以让它更接近正义。"
- "我们拥有神的能力，却不知道自己想要什么。"
