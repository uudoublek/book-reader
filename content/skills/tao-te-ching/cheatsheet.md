## 决策规则

| 当… | 用… |
|---|---|
| 面对复杂系统、想强力控制 | 道法自然，做辅助者（"以辅万物之自然而不敢为"） |
| 目标庞大、不知从何下手 | 图难于易（"天下大事必作于细"） |
| 与人争锋、陷入零和 | 不争之争（"夫唯不争，故天下莫能与之争"） |
| 急于求成、怕功亏一篑 | 慎终如始（"合抱之木生于毫末"） |
| 自己强横固执、硬碰硬 | 柔弱胜刚强（"坚强者死之徒"） |
| 纵欲逐物、迷失本心 | 去欲返朴（"圣人为腹不为目"） |
| 频繁干预团队/制度 | 治大国若烹小鲜，少折腾 |

## 与儒家的基本张力

- 儒家主"有为"（礼治、教化、正名），道家主"无为"（自然、少干预）
- 儒家重"文质彬彬"（文饰），道家重"朴"（返璞归真）
- 老子："夫礼者，忠信之薄而乱之首"（38 章）——对礼治的直接批评
- 二者构成中国思想的两极，互补多于对立（"儒道互补"）
