# 第四章 分则一：危害公共安全罪 + 破坏社会主义市场经济秩序罪（042–059）

## Core Idea
本章进入刑法分则。危害公共安全罪以"不特定多数人的生命财产安全"为保护法益，包括危险方法类犯罪与事故犯罪；破坏社会主义市场经济秩序罪则保护市场秩序，涵盖伪劣商品、走私、金融、其他经济犯罪。核心是理解各罪的**构成要件与罪与非罪界限**——尤其是"口袋罪"（以危险方法危害公共安全罪、非法经营罪）的滥用风险。

## 各节要义

### 危险方法类犯罪（042–044）
- **危险方法类犯罪（042）**：以放火、爆炸、决水、投放危险物质等危险方法危害公共安全。
- **投放危险物质罪（043）**：投毒等行为的认定。
- **以危险方法危害公共安全罪（044）**："口袋罪"的警惕——本罪与放火、爆炸等是同类概括，须严格限定"与放火等危险性相当"的方法，防止被滥用（如以本罪处理某些交通、高空抛物个案引起争议）。

### 事故犯罪（045–046）
- **交通肇事罪（045）**：违反交通运输管理法规，发生重大事故致人重伤、死亡或重大财产损失；"逃逸"情节的加重；肇事后"逃逸致人死亡"的特别加重。
- **危险驾驶罪（046）**：醉酒驾驶、追逐竞驶（飙车）等；醉驾入刑的讨论（情节是否显著轻微）。

### 伪劣商品犯罪（047–049）
生产、销售伪劣商品罪；食品安全犯罪（生产、销售不符合安全标准的食品）；生产、销售假药、劣药罪。罗翔强调：**假药/劣药认定中的"形式标准 vs 实质危害"**（如"陆勇案"中代购印度仿制药是否构成销售假药罪的争议）。

### 走私与公司犯罪（050–051）
走私罪（普通货物、珍贵动物、武器弹药等）；妨害对公司、企业的管理秩序罪（虚报注册资本、虚假出资等）。

### 金融犯罪（052–056）
- **贷款诈骗罪和骗取贷款罪（052）**：以非法占有为目的 vs 违规取得贷款的区分（是否"具有非法占有目的"是罪与非罪的关键）。
- **洗钱罪（053）**：为掩饰、隐瞒犯罪所得及其收益的来源和性质。
- **非法集资犯罪（054）**：非法吸收公众存款罪与集资诈骗罪的界限。
- **集资诈骗罪（055）**：以非法占有为目的的集资。
- **信用卡诈骗罪（056）**：恶意透支等的认定。

### 其他经济犯罪（057–059）
侵犯著作权罪、合同诈骗罪（以非法占有为目的骗取财物）、**非法经营罪（059）**——又一个"口袋罪"，罗翔提醒严格把握其适用范围，防止扩张。

## Key Takeaways
1. 危害公共安全罪保护"不特定多数人"的安全，与侵犯个人法益的犯罪相区别。
2. 交通肇事（过失）与危险驾驶（故意）是两类最常见的事故类犯罪。
3. 金融犯罪的罪与非罪，多取决于"非法占有目的"与"行政违法 vs 刑事犯罪"的界限。
4. "口袋罪"（以危险方法危害公共安全罪、非法经营罪）须严格限定，警惕扩张适用。
5. 食品安全、药品安全犯罪关系民生，罗翔以真实案件（如陆勇案）说明实质解释的重要性。
