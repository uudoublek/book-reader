# Cheatsheet — 总则体系 + 分则罪名速查

## 刑法总则骨架

```
刑法（犯罪人的大宪章）
├─ 基本原则：罪刑法定 / 罪刑相当 / 人人平等
├─ 犯罪论：四要件（主体·主观·客观·客体）
│   ├─ 排除事由：正当防卫（法不能向不法让步）·紧急避险
│   ├─ 未完成：预备 → 未遂 → 中止
│   └─ 共犯：正犯·帮助犯·教唆犯·主从胁从
└─ 刑罚论：主刑（管制/拘役/有期/无期/死刑）
    └─ 附加刑（罚金/剥夺政治权利/没收财产/驱逐出境）
        量刑（自首/立功/累犯/缓刑）→ 减刑/假释
```

## 刑事责任年龄速查

| 年龄 | 责任 |
|---|---|
| < 12 周岁 | 不负刑事责任 |
| 12–14 周岁 | 故意杀人/故意伤害致人死亡等，经最高检核准追诉 |
| 14–16 周岁 | 八类重罪负责（杀人/伤害致死/强奸/抢劫/贩毒/放火/爆炸/投毒） |
| ≥ 16 周岁 | 完全刑事责任 |

## 决策规则

| 当… | 用… |
|---|---|
| 判断行为是否犯罪 | 四要件 + 罪刑法定（法无明文规定不为罪） |
| 讨论见死不救 | 不作为犯须有作为义务；道德义务≠法律义务 |
| 分析防卫案件 | 法不能向不法让步；查侵害是否正在进行、是否明显过当 |
| 认定强奸 | 核心是"违背意志"；未满 14 周岁无性同意能力 |
| 区分盗窃/诈骗/抢劫 | 看占有转移方式：窃取/欺骗处分/暴力胁迫 |
| 讨论天价索赔 | 正当行使权利不构成敲诈勒索 |
| 评估死刑 | 少杀慎杀；三类人不适用（<18 岁、怀孕妇女、≥75 岁） |
| 反思公权力扩张 | 限制权力优先，警惕"最优选择"神话 |

## 一句话总纲

罗翔用"案例+法理+哲学"讲刑法：总则讲"怎么定罪、怎么处罚"（罪刑法定、四要件、正当防卫、少杀慎杀），分则讲"具体罪名怎么认"（人身、财产、经济、贪腐），再用《法治的细节》《刑罚的历史》《同意制度》补足法治哲学、刑罚演进与性同意的人性关怀——刑法最终是"限制权力、保护自由"的学科。
