# Glossary — 核心刑法术语

- **罪刑法定** — 法无明文规定不为罪，法无明文规定不处罚；限制国家刑罚权、保障公民自由。
- **罪刑相当** — 刑罚轻重与罪行、刑事责任相适应。
- **刑法面前人人平等** — 对特权与歧视的否定，罪刑适用不因人而异。
- **犯罪构成（四要件）** — 犯罪主体、犯罪主观方面、犯罪客观方面、犯罪客体。
- **刑事责任年龄** — 已满 16 周岁负完全责任；14–16 周岁对八类重罪负责；12–14 周岁经最高检核准追诉。
- **故意 / 过失** — 主观罪过的两种形式；过失分疏忽大意与过于自信。
- **作为 / 不作为** — 危害行为的两种形态；不作为犯以有作为义务为前提。
- **因果关系** — 危害行为与危害结果之间的引起与被引起关系。
- **正当防卫** — 对正在进行的不法侵害的制止行为；"法不能向不法让步"；特殊防卫无过当之限。
- **特殊防卫** — 针对行凶、杀人、抢劫、强奸、绑架等严重暴力犯罪，造成伤亡不负刑责。
- **紧急避险** — 为保护合法权益不得已损害另一较小权益。
- **犯罪预备** — 为犯罪准备工具、制造条件，未着手实行。
- **犯罪未遂** — 已着手实行，因意志以外原因未得逞。
- **犯罪中止** — 自动放弃犯罪或自动有效防止结果发生。
- **共同犯罪** — 二人以上共同故意犯罪；分主犯、从犯、胁从犯、教唆犯。
- **正犯 / 共犯** — 实行犯 / 帮助犯、教唆犯。
- **主刑** — 管制、拘役、有期徒刑、无期徒刑、死刑。
- **附加刑** — 罚金、剥夺政治权利、没收财产、驱逐出境。
- **死刑 / 死缓** — 最严厉主刑 / 死刑缓期二年执行制度。
- **量刑** — 以事实为根据、以法律为准绳确定刑罚。
- **自首** — 自动投案并如实供述，可从宽。
- **累犯** — 刑满后一定期限内再犯应判有期徒刑以上之罪，从重处罚。
- **缓刑** — 对判处拘役、三年以下有期徒刑者附条件不执行原判刑罚。
- **减刑 / 假释** — 服刑中因悔改立功减轻刑罚 / 附条件提前释放。
- **交通肇事罪** — 违反交规致重大事故；逃逸加重。
- **危险驾驶罪** — 醉驾、飙车等；不以实害结果为要件。
- **非法集资犯罪** — 非法吸收公众存款罪与集资诈骗罪的合称。
- **集资诈骗罪** — 以非法占有为目的的集资行为。
- **洗钱罪** — 掩饰、隐瞒犯罪所得及其收益的来源性质。
- **故意杀人罪** — 故意非法剥夺他人生命；分直接故意与间接故意。
- **强奸罪** — 以暴力、胁迫等手段违背妇女意志；奸淫幼女从重。
- **性同意年龄** — 法律推定无性同意能力的年龄（未满 14 周岁）。
- **拐卖妇女、儿童罪 / 收买被拐卖妇女、儿童罪** — 以出卖为目的 / 收买行为本身构成犯罪。
- **非法拘禁罪 / 绑架罪** — 非法剥夺自由 / 以勒索或人质为目的劫持。
- **虐待罪 / 遗弃罪** — 家庭成员间的虐待、遗弃，通常"告诉才处理"。
- **抢劫罪 / 抢夺罪** — 暴力劫取 / 公然夺取（未使用暴力）。
- **盗窃罪 / 诈骗罪 / 侵占罪** — 秘密窃取 / 虚构事实骗取 / 非法占有保管物。
- **敲诈勒索罪** — 以威胁、要挟索取财物；正当索赔不构成。
- **寻衅滋事罪** — 随意殴打、追逐拦截、强拿硬要等；罗翔警示"口袋罪"风险。
- **贪污罪 / 挪用公款罪** — 国家工作人员侵吞公共财物 / 挪用公款归个人使用。
- **受贿罪 / 行贿罪** — 利用职务便利收受财物为他人谋利 / 给予国家工作人员财物。
- **利用影响力受贿罪** — 近亲属、关系密切的人利用影响力受贿。
- **法治（Rule of Law）** — 维护秩序又限制秩序力量本身的"悖论性存在"。
- **圆圈正义** — 现实正义有瑕疵（画不出完美的圆），但正义客观存在、值得追求。
- **同意（Consent）** — 性犯罪认定的核心概念；真实同意 vs 无效同意（胁迫、欺骗、无能力）。
