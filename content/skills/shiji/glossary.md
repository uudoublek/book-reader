# Glossary — 核心术语

- **纪传体** — 以人物传记为中心组织历史的史书体例，司马迁首创，与编年体（《春秋》《左传》）、国别体（《国语》《战国策》）并立
- **通史** — 贯通古今的史书。《史记》是中国第一部纪传体通史，上起黄帝、下至汉武帝
- **本纪** — 记帝王政迹的编年体篇章，全书纲领（十二篇）
- **表** — 以年月为纲、提纲挈领记大事的表格（十篇）
- **书** — 记典章制度与经济文化的专题（八篇：礼乐律历、天官封禅、河渠平准）
- **世家** — 记诸侯列国及有重大影响人物的篇章（三十篇），孔子、陈涉破格入世家
- **列传** — 记各阶层人物的篇章（七十篇），含类传（循吏、酷吏、游侠、货殖等）与民族传（匈奴、南越等）
- **互见法** — 同一事件/人物在不同篇章详略互见、避免重复的叙事手法，须合观方得全貌
- **太史公曰** — 每篇末尾司马迁的论赞，是其史评与褒贬倾向的集中体现
- **实录** — 班固评《史记》"其文直，其事核，不虚美，不隐恶"的直书精神
- **发愤著书** — 司马迁因李陵之祸受宫刑后忍辱著史，以"文王拘而演《周易》"等自勉（《报任安书》）
- **究天人之际，通古今之变，成一家之言** — 司马迁自述的著史宗旨
- **原始察终，见盛观衰** — 推究本原、考察结局、于盛世见衰象的治史方法
- **五帝** — 黄帝、颛顼、帝喾、尧、舜，远古传说中相继为帝的五位部落首领
- **禅让** — 尧舜禹相传的"选贤与能"的权力交接方式，司马迁笔下的理想政体
- **过秦** — 贾谊《过秦论》批评秦"仁义不施而攻守之势异也"而速亡
- **楚汉之争** — 项羽与刘邦争夺天下的战争（前206—前202），刘邦以"知人善任"胜项羽"刚愎自用"
- **文景之治** — 汉文帝、景帝两代与民休息的治世，为武帝盛世奠基
- **合纵连横** — 苏秦倡六国合纵抗秦、张仪倡连横事秦的纵横策略
- **远交近攻** — 范雎为秦提出的"结交远邦、攻取近邻"的统一策略
- **战国四公子** — 孟尝君（齐）、平原君（赵）、信陵君（魏）、春申君（楚），皆以养士著称
- **胡服骑射** — 赵武灵王改胡服、习骑射的军事改革，移风易俗、富国强兵
- **商鞅变法** — 商鞅在秦"徙木立信"、废井田、奖耕战，使秦富强而终被车裂
- **推恩令** — 主父偃"诸侯得推恩分子弟"之策，名为推恩、实则削藩
- **七国之乱** — 吴王刘濞等七国以"清君侧"反叛（前154），周亚夫平定
- **萧规曹随** — 曹参继萧何为相，一遵其约束、清静无为，让百姓休养生息
- **兔死狗烹** — "飞鸟尽，良弓藏；狡兔死，走狗烹"，功臣在权力倾轧下的命运
- **士为知己者死** — 刺客列传、管晏列传贯穿的精神母题，豫让"国士遇我，我故国士报之"
- **奇货可居** — 吕不韦以商人眼光投资秦质子子楚，窃取秦权
- **仓鼠之叹** — 李斯见厕鼠与仓鼠之异而悟"人之贤不肖譬如鼠矣，在所自处耳"
- **负荆请罪** — 廉颇肉袒负荆向蔺相如谢罪，"将相和"的典故
- **纸上谈兵** — 赵括空谈兵法致长平之败，重言轻行的教训
- **破釜沉舟 / 四面楚歌 / 鸿门宴 / 乌江自刎** — 项羽本纪的经典情节
- **卧薪尝胆** — 越王句践忍辱复国的典故
- **桃李不言，下自成蹊** — 司马迁赞李广身教胜于言传
- **冯唐易老，李广难封** — 贤才不遇的慨叹（张释之冯唐、李将军列传）
- **货殖** — 谋求"滋生资货财利"的经营活动，司马迁肯定求富的合理性
- **游侠** — 重信守诺、赴人厄困的布衣侠士，司马迁为其立传
- **循吏 / 酷吏 / 佞幸** — 司马迁区分的三类官吏：奉职循理的贤吏、严刑峻法的酷吏、谄媚取宠的佞臣
- **发愤之所为作** — "文王拘而演《周易》，仲尼厄而作《春秋》，屈原放逐乃赋《离骚》"——司马迁借以自勉的创作观
