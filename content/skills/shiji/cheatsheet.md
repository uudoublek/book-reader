## 决策规则

| 当… | 用… |
|---|---|
| 组建团队、知人善任 | 刘邦用三杰："吾能用之，此吾所以取天下" |
| 功高震主、进退两难 | 范蠡张良：急流勇退，"狡兔死，走狗烹" |
| 治理从打天下转向守天下 | 陆贾："逆取顺守，文武并用" |
| 面对强敌、正面难胜 | 出奇制胜：火牛阵、背水一战、围魏救赵 |
| 决策只听一面之词 | "兼听则明，偏信则暗" |
| 重大挫折、意义感崩塌 | 发愤著书："或重于泰山，或轻于鸿毛" |
| 判断政权兴衰 | "仁义不施而攻守之势异也"（过秦） |
| 识别组织盛极而衰 | 三信号：上层骄奢 + 功臣受忌 + 民力耗尽 |
