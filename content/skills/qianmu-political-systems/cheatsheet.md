# Cheatsheet — 五代制度对照速查

## 五代总览表

| 维度 | 汉 | 唐 | 宋 | 明 | 清 |
|---|---|---|---|---|---|
| 中央政制 | 三公九卿，丞相领袖制 | 三省六部，委员制 | 二府三司，相权分割 | 废宰相，内阁票拟 | 军机处，秘密政治 |
| 相权强弱 | 强（真领袖） | 强（盖章方成诏） | 弱（面取进止） | 无（权臣vs大臣） | 无（私人秘书） |
| 用人制度 | 察举（孝廉+贤良） | 科举（怀牒自列） | 科举（糊名防弊） | 八股+进士翰林 | 科举+特简引见 |
| 赋税 | 田租三十税一+盐铁官营 | 租庸调→两税 | 免役钱（差役改摊派） | 黄册鱼鳞+一条鞭 | 地丁摊粮（永不加赋） |
| 兵制 | 全国皆兵（更卒戍卒） | 府兵（寓农于兵） | 募兵（禁军厢军） | 卫所制 | 八旗绿营 |
| 地方 | 郡县两级，吏治称美 | 监察变行政，节度坐大 | 中央集权，地方贫弱 | 行省+监司，管官多 | 督抚常设五级 |
| 政权性质 | 士人政权 | 士人政权 | 士人政权 | 士人政权（变） | 部族政权 |
| 钱穆总评 | 合理化开明进步 | 最大转捩中枢 | 最贫最弱无建树 | 大大退步 | 全无制度只有法术 |

## 决策规则

| 当看到… | 判断… |
| --- | --- |
| 皇帝绕过宰相直接下诏 | 相权旁落信号（唐斜封墨敕、宋面取进止、清寄信上谕） |
| 监察官长期驻地方 | 有变成地方长官的风险（唐观察使→节度使） |
| 中央把军权财权用人权全收走 | 地方必贫弱，中央一败全国瓦解（宋） |
| 考试只重防弊 | 防弊过甚反不得真才（宋糊名） |
| 录取标准过度客观化 | 流弊如八股，"斲丧人才"但非一人之罪 |
| 制度推行两三百年 | 必出毛病（卫所、黄册鱼鳞皆然），"总不免" |
| 政令秘密发出不经机关 | 法术而非制度（清寄信上谕） |
| 官员人人可单独上奏互不知情 | 机关解体、无人负责（清满汉复职） |
| 政权背后站着一个部族 | 部族专制而非皇帝专制（元清） |
| 政府减轻田租 | 只便宜地主，农民未受分毫好处 |
| 用今人眼光否定古制 | 违反"历史意见"原则——"壮年人不要睡摇篮，但在婴孩期睡摇篮未必要不得" |
| 模仿抄袭外国制度 | 须与本国人事配合，否则"无生命的政治，无配合的制度，决然无法长成" |

## 核心论断（钱穆）

- **"若说专制，明清可以；若论汉唐宋，皇权相权是划分的"** — 全书"反专制黑暗论"的最终表述
- 中国政治传统两大趋势：**中央集权地方没落** + **社会平铺而无力量**
- 制度须"共尊共信"之心理支持——革命之后还须心理建设（孙中山）
- "不够的不在法，而在才"——法当使人才得表现，不可一味抄袭西方
- 中国政治比西方先进步（就制度史而言）——历史是客观事实，"历史使人不武断"（罗素）

## 名句速记

- 历史意见优先："以当时人的眼光看当时制度"
- 制度流变："任何一制度之成立，绝非此制度可以单独成立的"
- 中央地方："广土众民必得统一，而实不宜过分中央集权"
- 政务归属：唐代"不经凤阁鸾台，何得为敕" vs 清代寄信上谕——公私之别判然
- 相权价值：明代"不是宰相而问事揽权者，是权臣，非大臣"（张居正案）
