# Glossary — 核心术语

- **存在（Sein）** — 逻辑学的开端，无规定性的直接性，即"纯有"；被扬弃后成为"本质"的环节。
- **本质（Wesen）** — 存在的真理，反思的、间接的范畴；范畴成双相对地出现（同一/差异等）。
- **概念（Begriff）** — 存在与本质的统一，具体的普遍性，自由的、回复到自身的全体。
- **有与无** — 纯有因无规定性即是无；有与无的真理是两者的统一（变易）。
- **变易（Werden）** — 有与无的统一，第一个具体的思想范畴（"一切皆流"）。
- **定在（Dasein）** — 变易的结果，具有规定性的存在（限有）。
- **质（Qualität）** — 与存在直接同一的规定性；某物失其质即不再是某物。
- **量（Quantität）** — 与存在不相干的外在规定性；大小增减不改变质。
- **尺度（Maß）** — 质与量的统一；量超出限度即引起质变。
- **扬弃（Aufhebung）** — 取消与保存的双重含义：否定又保留，降为更高统一体的环节。
- **否定之否定** — 直接性→否定→回复自身（重新肯定），辩证法的基本运动形式。
- **自在（Ansich）** — 潜在、尚未展开的规定。
- **自为（Fürsich）** — 回复到自身、意识到自身的规定。
- **自在自为（An-und-für-sich）** — 潜在与实现的统一，概念的完备状态。
- **知性（Verstand）** — 坚持抽象同一、固定区别的思维阶段（非此即彼）。
- **理性（Vernunft）** — 把握对立面统一的思辨思维。
- **理念（Idee）** — 概念与客观性的绝对统一，绝对真理；分生命、认识、绝对理念。
- **绝对理念（absolute Idee）** — 理论理念与实践理念的统一，纯思维的最高范畴。
- **真理是全体** — 真理不是孤立结论，而是概念自身展开的全部过程。
- **现实（Wirklichkeit）** — 本质与现象的统一；"凡是现实的都是合理的"。
- **实存（Existenz）** — 有根据的、有条件的存在（区别于"存在"与"现实"）。
- **现象（Erscheinung）** — 本质的表现；本质与现象的统一（现象是本质的显现）。
- **实体（Substanz）** — 自因的、必然性的总体（斯宾诺莎）；经因果到相互作用。
- **相互作用（Wechselwirkung）** — 本质关系的最高范畴，原因与结果互为前提，过渡到概念。
- **坏的无限 / 真正的无限** — 无穷进展（同一事情重演）vs"在别物中即是在自己中"。
- **具体普遍性** — 概念不是抽象共同点，而是包含特殊与个别的普遍。
- **思想对客观性的三种态度** — 形而上学、经验主义与批判哲学、直接知识。
