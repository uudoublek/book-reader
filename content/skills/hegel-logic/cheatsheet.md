# Cheatsheet — 三篇结构 + 关键命题速查

## 全书三篇结构

| 篇 | 节 | 三环节 | 主题 |
|---|---|---|---|
| 存在论 | §84–§111 | 质 → 量 → 尺度 | 思想的直接性（有/无/变、质量度） |
| 本质论 | §112–§159 | 本质 → 现象 → 现实 | 思想的反思性（同一/差异、实体/因果） |
| 概念论 | §160–§244 | 主观概念 → 客体 → 理念 | 回复到自身（概念/判断/推论、绝对理念） |

## 关键范畴演进链

```
纯有 → 无 → 变易 → 定在 → 质 → 量 → 尺度 → 本质 → 现象 → 现实
→ 主观概念 → 客体 → 理念（生命 → 认识 → 绝对理念）
```

## 关键命题速查

| 命题 | 出处 | 含义 |
|---|---|---|
| 凡是现实的都是合理的，凡是合理的都是现实的 | 序言 | 现实=合乎理性的存在（≠现存） |
| 有与无的真理就是变易 | §88 | 纯有即无，统一于变 |
| 一切规定都是否定 | §91（引斯宾诺莎） | 规定性即否定性 |
| 在别物中即是在自己中 | §94 | 真正的无限 |
| 矛盾是一切运动和生命力的根源 | §119 | 同一内含差异、矛盾 |
| 真理是全体 | 序言/导言 | 真理是概念展开的全过程 |
| 理念是概念与客观性的绝对统一 | §213 | 主客统一、绝对真理 |

## 决策规则

| 当… | 用… |
|---|---|
| 分析一个概念如何发展 | 有→无→变，正反合的三段运动 |
| 否定旧观点/旧体系 | 扬弃：取消又保存，降为环节 |
| 判断量变是否引起质变 | 尺度：识别限度与临界点 |
| 面对非此即彼的两难 | 对立统一，从知性升到理性 |
| 评估"存在的即合理吗" | 区分现实（合理）与现存（偶然） |
| 陷入循环论证/无穷进展 | 警惕坏的无限，回复到自身 |

## 三种思想态度（供批判）

| 态度 | 代表 | 缺陷 |
|---|---|---|
| 形而上学 | 旧形而上学 | 抽象知性独断，把有限谓词加给绝对 |
| 经验主义与批判哲学 | 康德 | 割裂现象与物自体 |
| 直接知识 | 耶柯比 | 排斥中介，凭直觉直达 |

## 译名对照（贺麟译）

| 德文 | 贺麟译 | 注意 |
|---|---|---|
| Sein | 存在 | 旧译"有"；与 Existenz 区分 |
| Existenz | 实存 | 有根据的存在 |
| Wirklichkeit | 现实 | 本质与现象的统一 |
| Begriff | 概念 | 旧译"总念" |
| Verstand / Vernunft | 知性 / 理性 | 认识能力的两阶段 |
| Aufhebung | 扬弃 | 取消 + 保存 |
