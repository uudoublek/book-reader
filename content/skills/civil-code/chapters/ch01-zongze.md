# 第一编 总则 — 民法的总纲

## Core Idea
总则编（第1–204条）是民法典的"总纲"，规定民法的调整对象、基本原则、民事主体、民事权利、民事法律行为、代理、民事责任与诉讼时效，是其他各编共同适用的通用规则。核心是确立"平等主体 + 意思自治 + 诚信公平"的民法精神。

## 各章要点

### 第一章 基本规定（第1–12条）
立法目的：保护民事权益、调整民事关系、弘扬社会主义核心价值观。**民法调整平等主体的自然人、法人和非法人组织之间的人身关系和财产关系**（第2条）。六项基本原则：平等（第4条）、自愿（第5条）、公平（第6条）、诚信（第7条）、守法与公序良俗（第8条）、绿色（第9条）。处理民事纠纷依法律，法律无规定的可适用习惯但不得违背公序良俗（第10条）。

### 第二章 自然人（第13–56条）
- **民事权利能力**：始于出生、终于死亡，一律平等（第13–14条）；胎儿利益保护（第16条）。
- **民事行为能力**：十八周岁以上为成年人、完全民事行为能力人（第17–18条）；八周岁以上为限制民事行为能力人（第19条）；不满八周岁为无民事行为能力人（第20条）。
- **监护**：父母为未成年子女监护人；无/限制行为能力成年人的监护顺序（配偶→父母子女→其他近亲属）；"最有利于被监护人"原则（第35条）；监护资格的撤销与恢复。
- **宣告失踪与宣告死亡**：下落不明满二年可宣告失踪（第40条）；满四年（或意外事件满二年）可宣告死亡（第46条）；宣告撤销后的法律后果（婚姻、财产返还）。
- **个体工商户与农村承包经营户**：以个人/家庭财产承担债务（第56条）。

### 第三章 法人（第57–75条）
法人是具有民事权利能力和民事行为能力、依法独立享有权利承担义务的组织；以**全部财产独立承担责任**（第60条）；分**营利法人**（公司等）、**非营利法人**（事业单位、社会团体、基金会等）、**特别法人**（机关、农村集体经济组织、城镇农村合作经济组织、基层群众性自治组织）。

### 第四章 非法人组织（第102–108条）
个人独资企业、合伙企业、不具有法人资格的专业服务机构等，以自己的财产承担责任，出资人/设立人承担无限责任（第104条）。

### 第五章 民事权利（第109–132条）
自然人的人身自由、人格尊严受保护；财产权利（物权、债权、知识产权、股权等）体系化列举；"权利不得滥用"原则。

### 第六章 民事法律行为（第133–160条）
以意思表示为要素设立、变更、终止民事关系的行为。**无效情形**：违反法律行政法规强制性规定、违背公序良俗、恶意串通（第153–154条）；**可撤销情形**：重大误解、欺诈、胁迫、显失公平（第147–151条）。可附条件、附期限。

### 第七章 代理（第161–175条）
委托代理与法定代理；代理人以被代理人名义实施法律行为，后果由被代理人承受；无权代理、表见代理的效力规则（第171–172条）；代理终止情形。

### 第八章 民事责任（第176–187条）
民事主体依法律规定或约定承担民事责任；责任方式包括停止侵害、排除妨碍、返还财产、恢复原状、赔偿损失、赔礼道歉等；不可抗力免责；正当防卫、紧急避险的规则。

### 第九章 诉讼时效（第188–199条）
**普通诉讼时效三年**（第188条），自权利人知道或应当知道权利受损及义务人之日起算；最长权利保护期间二十年；诉讼时效届满的后果是义务人取得抗辩权（而非权利消灭）。

### 第十章 期间计算（第200–204条）
按公历年月日计算期间的技术规则。

## Key Takeaways
1. 六项基本原则（平等、自愿、公平、诚信、公序良俗、绿色）是全部民法的灵魂。
2. 行为能力三分：完全（≥18 岁）、限制（8–18 岁）、无（<8 岁）。
3. 法人独立责任是市场交易的制度基石。
4. 普通诉讼时效三年，"权利不用则废"。
5. 民事法律行为的效力体系（无效/可撤销/效力待定）是交易安全的核心保障。
