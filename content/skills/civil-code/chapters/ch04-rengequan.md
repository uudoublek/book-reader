# 第四编 人格权 — 人的尊严的立法保障

## Core Idea
人格权编（第989–1039条）是民法典的**世界性创新**——将人格权独立成编，宣告"自然人的人身自由、人格尊严受法律保护"（第990条）。它以"人"而非"财产"为中心，系统规定生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权和个人信息保护，体现了人本主义的立法价值。

## 各章要点

### 第一章 一般规定（第989–999条）
**人格权定义**（第990条）：生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等权利，以及基于人身自由、人格尊严产生的其他人格权益。人格权不得放弃、转让、继承（第992条）；死者人格利益受保护（第994条）；人格权受到侵害的救济方式（停止侵害、排除妨碍、消除危险、消除影响、恢复名誉、赔礼道歉等）；违约与侵权竞合时精神损害赔偿（第996条）。

### 第二章 生命权、身体权和健康权（第1002–1011条）
自然人的生命、身体、健康受法律保护；器官捐献须自愿；性骚扰的禁止与单位防治义务（第1010条）；人体基因、胚胎等医学研究须遵守法律与伦理。

### 第三章 姓名权和名称权（第1012–1021条）
自然人享有姓名权，有权依法决定、使用、变更、许可他人使用自己的姓名；法人、非法人组织享有名称权；盗用、冒用、干涉他人姓名/名称构成侵权。

### 第四章 肖像权（第1018–1023条）
自然人享有肖像权，未经同意不得制作、使用、公开其肖像；**AI 换脸等"深度伪造"被明确规制**（第1019条：不得利用信息技术手段伪造等方式侵害肖像权）；肖像合理使用情形（新闻报道、公共事务等）。

### 第五章 名誉权和荣誉权（第1024–1031条）
名誉权：任何组织个人不得以侮辱、诽谤等方式侵害他人名誉；新闻报道、舆论监督与名誉权保护的平衡（第1025条）；荣誉权：非法剥夺他人荣誉称号构成侵权。

### 第六章 隐私权和个人信息保护（第1032–1039条）
- **隐私权**（第1032条）：私人生活安宁和不愿为他人知晓的私密空间、私密活动、私密信息受保护；不得以刺探、侵扰、泄露、公开等方式侵害。
- **个人信息保护**（第1034–1039条）：自然人的个人信息受法律保护；处理个人信息须遵循合法、正当、必要原则并征得同意；信息处理者的安全保护义务。

## Key Takeaways
1. 人格权独立成编是世界民事立法首创，宣告"人是目的而非手段"。
2. 肖像权规制扩展到"深度伪造"（AI 换脸），回应数字时代。
3. 隐私权保护"私人生活安宁"，个人信息处理须合法正当必要+同意。
4. 死者人格利益与英雄烈士人格利益受特别保护。
5. 人格权救济不以财产损失为前提，精神损害赔偿可独立主张。
