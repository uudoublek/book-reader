# 第三编 合同 — 交易的规则

## Core Idea
合同编（第463–988条）是民法典篇幅最大的编，规定合同从订立、效力、履行到违约责任的全生命周期规则，分三个分编：通则、典型合同、准合同。核心命题是"**依法成立的合同，自成立时生效**"（第502条），契约自由与诚信履行是灵魂。

## 各分编要点

### 第一分编 通则（第463–597条）
- **合同的订立**（第469–501条）：要约与承诺；书面/口头/其他形式；格式条款的提示说明义务（第496条）与无效情形（第497条）。
- **合同的效力**（第502–508条）：成立即生效为原则；效力待定（限制行为能力人）、无效、可撤销情形适用总则规则。
- **合同的履行**（第509–536条）：全面履行、诚信履行；履行规则（标的、地点、期限不明时）；不安抗辩权、先履行抗辩权、同时履行抗辩权（第525–527条）。
- **合同的保全**（第535–537条）：债权人代位权与撤销权，防止债务人转移财产损害债权。
- **合同的变更和转让**（第543–556条）：债权转让、债务转移的规则与通知义务。
- **合同的权利义务终止**（第557–576条）：履行、解除、抵销、提存、免除、混同；法定解除权情形（第563条）。
- **违约责任**（第577–597条）：不履行或履行不符合约定，承担继续履行、补救措施、赔偿损失等责任（第577条）；违约金调整规则（第585条）；定金规则（第586–588条）。

### 第二分编 典型合同（第595–978条）
27 类典型合同：**买卖合同**（标的物所有权转移、瑕疵担保）、**供用电水气热力合同**、**赠与合同**（任意撤销与法定撤销）、**借款合同**（利息限制）、**保证合同**（保证方式、保证人抗辩权〔第701条〕、保证期间）、**租赁合同**（租期最长二十年、转租规则、买卖不破租赁）、**融资租赁合同**、**保理合同**（新增）、**承揽合同**、**建设工程合同**（禁止转包）、**运输合同**、**技术合同**、**保管合同**、**仓储合同**、**委托合同**（任意解除权）、**物业服务合同**（新增）、**行纪合同**、**中介合同**、**合伙合同**（新增）。

### 第三分编 准合同（第979–988条）
- **无因管理**（第979条起）：没有法定或约定义务，为避免他人利益受损失而管理他人事务，管理人有权请求受益人偿还必要费用。
- **不当得利**（第985条起）：没有法律根据取得不当利益，受损失的人有权请求返还。

## Key Takeaways
1. 契约自由 + 诚实信用是合同编的两翼：成立即生效，履行须诚信。
2. 违约责任体系：继续履行、补救、赔偿损失；违约金过高可请求调整。
3. 三种抗辩权（同时/先履行/不安）保护交易双方在履行中的利益。
4. 典型合同 27 类覆盖日常交易，新增保理、物业服务、合伙合同回应时代需要。
5. 无因管理与不当得利构成"准合同"，填补合同外的债因空隙。
