# 第五编 婚姻家庭 + 第六编 继承 — 家事法

## Core Idea
本部分覆盖婚姻家庭编（第1040–1118条）与继承编（第1119–1163条）。婚姻家庭编规定结婚、家庭关系、离婚、收养，强调婚姻自由、一夫一妻、男女平等、保护妇女儿童老年人合法权益，并确立**离婚冷静期**；继承编规定法定继承、遗嘱继承与遗赠、遗产处理，确立继承权平等与遗嘱自由。

## 婚姻家庭编要点

### 结婚（第1046–1054条）
结婚自愿（禁止包办、买卖婚姻）；法定婚龄（男二十二周岁、女二十周岁）；**禁止近亲结婚**（直系血亲或三代以内旁系血亲）；无效婚姻与可撤销婚姻（胁迫、隐瞒重大疾病）。

### 家庭关系（第1055–1075条）
- **夫妻关系**：夫妻平等；**夫妻共同财产**（第1062条）：婚姻关系存续期间所得的工资、奖金、投资收益、知识产权收益、继承或受赠财产（遗嘱或赠与合同确定只归一方的除外）等归共同所有；**个人财产**（第1063条）：婚前财产、人身损害赔偿、遗嘱赠与确定归一方的财产等；**约定财产制**（第1065条）：可书面约定分别所有、共同所有等。
- **父母子女关系**：抚养、赡养、教育义务；非婚生子女与婚生子女权利平等；继父母子女关系。

### 离婚（第1076–1092条）
**协议离婚**（第1076条）：双方自愿签订书面协议，到婚姻登记机关申请；**离婚冷静期**（第1077条）：自申请之日起三十日内任何一方可撤回——适用于协议离婚（诉讼离婚不适用）；**诉讼离婚**（第1079条）：感情确已破裂调解无效准予离婚（含重婚、家暴、遗弃、赌博吸毒恶习屡教不改、分居满二年等情形）；离婚后子女抚养、财产分割、经济补偿与家务劳动补偿（第1088条）。

### 收养（第1093–1118条）
被收养人（未成年人）与收养人条件；收养须向民政部门登记；收养关系成立后养父母与养子女间的权利义务适用父母子女关系规定；收养关系可解除。

## 继承编要点

### 法定继承（第1127–1131条）
继承从被继承人死亡时开始。**法定继承顺序**：第一顺序——配偶、子女、父母；第二顺序——兄弟姐妹、祖父母、外祖父母。继承开始后由第一顺序继承人继承，第二顺序不继承；没有第一顺序的，由第二顺序继承。同一顺序继承人继承份额一般均等，对被继承人尽了主要扶养义务或共同生活的可多分；有扶养能力和条件而不尽扶养义务的，应当不分或少分。

### 遗嘱继承和遗赠（第1133–1144条）
自然人可以立遗嘱处分个人财产（**第1133条**），指定遗嘱执行人、将财产指定给法定继承人（遗嘱继承）或国家、集体、法定继承人以外的组织个人（遗赠）。遗嘱形式：自书、代书、打印、录音录像、口头、公证遗嘱；**公证遗嘱效力优先规则已取消**，数份遗嘱内容相抵触的，以最后的遗嘱为准（第1142条）；遗嘱应当为缺乏劳动能力又没有生活来源的继承人保留必要份额（必留份）。

### 遗产的处理（第1145–1163条）
遗产管理人制度；继承开始后遗产分割；清偿债务以遗产实际价值为限（限定继承原则）；无人继承又无人受遗赠的遗产归国家所有（用于公益事业），死者生前为集体组织成员的归集体所有。

## Key Takeaways
1. 夫妻共同财产（第1062条）与约定财产制（第1065条）是婚姻财产的核心规则。
2. 离婚冷静期 30 日只适用于协议离婚（第1077条），诉讼离婚不受限。
3. 法定继承顺序：第一顺序（配偶、子女、父母）优先于第二顺序（兄弟姐妹、祖父母、外祖父母）。
4. 数份遗嘱以最后一份为准，"公证遗嘱效力优先"已废除（第1142条）。
5. 限定继承：继承人清偿债务以遗产实际价值为限，父债子偿无法律根据。
