# 第二编 物权 — 财产的支配与保护

## Core Idea
物权编（第205–462条）规定人对物直接支配并排除他人干涉的权利，分五个分编：通则、所有权、用益物权、担保物权、占有。核心原则是**物权法定**（物权的种类和内容由法律规定）与**公示公信**（不动产登记、动产交付）。本编的亮点是新增**居住权**，落实"住有所居"。

## 各分编要点

### 第一分编 通则（第205–239条）
物权是权利人依法对特定的物享有直接支配和排他的权利（第205条）；**物权法定**（第116条）；物权的设立、变更、转让和消灭以登记（不动产）或交付（动产）为公示方式（第208–231条）；物权的保护：确认权利、返还原物、排除妨害、消除危险、损害赔偿（第233–238条）。

### 第二分编 所有权（第240–320条）
- **所有权定义**（第240条）：对自己的不动产或动产依法享有占有、使用、收益、处分的权利。
- **国家所有权**：矿藏、水流、海域、无居民海岛、城市的土地等归国家所有；**集体所有权**：农村土地等归集体所有；**私人所有权**：合法私有财产受法律保护。
- **业主的建筑物区分所有权**（第271条起）：业主对专有部分享有所有权、对共有部分享有共有和共同管理的权利；维修资金、物业费、业主大会规则。
- **相邻关系**（第288–296条）：不动产相邻各方应有利生产、方便生活、团结互助、公平合理，正确处理用水、排水、通行、通风、采光等关系。
- **共有**（第297–310条）：按份共有与共同共有；共有物的处分须经三分之二以上份额共有人同意（按份共有）。

### 第三分编 用益物权（第323–385条）
用益物权人对他人所有的不动产或动产享有占有、使用和收益的权利：
- **土地承包经营权**：承包土地的占有、使用、收益权，可依法流转。
- **建设用地使用权**：开发利用国有土地的权能。
- **宅基地使用权**：农村村民建造住宅的用益物权。
- **居住权**（第366条，本编亮点）：居住权人有权按合同约定对他人的住宅享有占有、使用的用益物权，以满足生活居住需要；居住权无偿设立、须登记、不得转让继承，一般限于居住目的。

### 第四分编 担保物权（第386–462条）
债权人对担保财产享有优先受偿的权利：
- **抵押权**（第394条起）：不转移占有的担保，可抵押财产范围（第395条）；不动产抵押自登记时设立（第402条）。
- **质权**：动产质权（转移占有）、权利质权（股权、债权、知识产权等）。
- **留置权**：债务人不履行到期债务，债权人可留置已合法占有的债务人动产。

### 第五分编 占有（第458–462条）
占有状态本身受保护；占有人对侵占、妨害可请求返还原物、排除妨害。

## Key Takeaways
1. 物权法定 + 公示公信：不登记（不动产）/不交付（动产）不产生物权效力。
2. 所有权四权能：占有、使用、收益、处分。
3. 居住权是新增用益物权，专为"住有所居"而设，须登记、不得转让。
4. 担保物权是融资的基石：抵押不转移占有、质押转移占有、留置基于合法占有。
5. 相邻关系与共有规则，是处理邻里与共同财产纠纷的直接依据。
