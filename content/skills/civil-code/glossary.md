# Glossary — 核心法律术语

- **民事主体** — 自然人、法人、非法人组织，是民事权利义务的承担者。
- **民事权利能力** — 依法享有民事权利、承担民事义务的资格，始于出生终于死亡。
- **民事行为能力** — 以自己的行为取得权利、承担义务的能力；分完全/限制/无三种。
- **监护人** — 对无/限制行为能力人负保护职责的人（父母、近亲属、民政部门等）。
- **宣告失踪 / 宣告死亡** — 下落不明满二年/四年（意外事件满二年）经申请由法院宣告的制度。
- **法人** — 依法独立享有权利、承担义务的组织，以全部财产独立担责。
- **营利法人 / 非营利法人 / 特别法人** — 法人的三种类型。
- **民事法律行为** — 以意思表示为要素设立、变更、终止民事法律关系的行为。
- **意思表示** — 民事法律行为的核心要素，指向外部表明意图的行为。
- **代理** — 代理人以被代理人名义实施法律行为，后果由被代理人承受。
- **表见代理** — 相对人有理由相信行为人有代理权的，代理行为有效。
- **诉讼时效** — 请求法院保护民事权利的期间，普通为三年（第188条）。
- **物权** — 对物直接支配并排除他人干涉的权利，物权法定。
- **所有权** — 占有、使用、收益、处分四项权能的完整物权（第240条）。
- **用益物权** — 对他人之物占有、使用、收益的权利（土地承包经营权、建设用地使用权、宅基地使用权、居住权、地役权）。
- **居住权** — 对他人的住宅占有、使用以满足居住需要的用益物权（第366条）。
- **担保物权** — 对担保财产优先受偿的权利（抵押权、质权、留置权）。
- **抵押权** — 不转移占有、以登记设立的担保物权（第395条）。
- **质权** — 转移占有的担保物权（动产质权、权利质权）。
- **留置权** — 合法占有他人动产，债务人不履行到期债务时留置该动产的担保物权。
- **占有** — 对物的实际控制状态，本身受法律保护。
- **债权** — 请求特定人为或不为一定行为的权利。
- **合同** — 民事主体之间设立、变更、终止民事法律关系的协议。
- **要约 / 承诺** — 合同订立的两大步骤。
- **格式条款** — 预先拟定、重复使用的条款，提供方须提示说明，不公平条款无效。
- **违约责任** — 不履行或履行不符合约定时承担的责任（第577条）。
- **代位权 / 撤销权** — 债权人保全债权的两项权利（合同编）。
- **定金** — 担保债权的金钱，交付方违约不返还、收受方违约双倍返还。
- **无因管理** — 无法定义务为他人管理事务，可请求偿还必要费用（准合同）。
- **不当得利** — 无法律根据取得利益致他人受损，应返还（准合同）。
- **人格权** — 生命权、身体权、健康权、姓名权、名称权、肖像权、名誉权、荣誉权、隐私权等（第990条）。
- **隐私权** — 私人生活安宁和私密信息不受侵害的权利（第1032条）。
- **个人信息** — 可单独或结合识别特定自然人的各种信息，受法律保护。
- **夫妻共同财产** — 婚姻关系存续期间所得的工资、投资收益等共同财产（第1062条）。
- **约定财产制** — 夫妻书面约定财产归属的制度（第1065条）。
- **离婚冷静期** — 协议离婚登记后三十日内可撤回的期间（第1077条）。
- **法定继承** — 依法律规定的顺序和份额继承（第一顺序：配偶、子女、父母）。
- **遗嘱继承 / 遗赠** — 依遗嘱将财产指定给法定继承人（继承）/法定继承人以外的人或组织（遗赠）。
- **必留份** — 遗嘱须为缺乏劳动能力又无生活来源的继承人保留的必要份额。
- **限定继承** — 继承人清偿债务以遗产实际价值为限。
- **过错责任** — 有过错才担责的归责原则（第1165条）。
- **无过错责任** — 法律规定不问过错仍担责的归责原则（第1166条）。
- **自甘风险** — 自愿参加有一定风险的文体活动，其他参加者无故意/重大过失不担责（第1176条）。
- **好意同乘** — 非营运机动车无偿搭乘，减轻机动车一方责任（第1217条）。
- **高空抛物** — 禁止从建筑物抛掷物品，致害由侵权人担责（第1254条）。
