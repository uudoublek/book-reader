## 决策规则

| 当… | 用… |
|---|---|
| 判断行为是否受民法调整 | 先看是否"平等主体间的人身/财产关系"（第2条） |
| 主张权利之前 | 先查诉讼时效（三年，第188条），留书面证据中断时效 |
| 评估合同效力 | 成立→生效→效力分层检验；查欺诈胁迫重大误解显失公平 |
| 判断侵权责任 | 过错（1165）→过错推定→无过错（1166），再查免责事由 |
| 处理婚姻财产 | 先定性（共同1062/个人1063）→约定（1065）→分割 |
| 处理继承 | 第一顺序（配偶子女父母）→第二顺序→遗嘱优先（含必留份）→限定继承 |
| 购房/借贷/签约 | 尽职核查：登记查询、主体资格、格式条款、担保方式 |

## 侵权归责速查

| 情形 | 归责原则 |
|---|---|
| 一般侵权 | 过错责任（1165） |
| 动物园动物致害 | 过错推定 |
| 产品缺陷、高度危险、饲养动物、环境污染 | 无过错责任（1166 等） |
| 文体活动受伤（无故意重大过失） | 免责（自甘风险，1176） |
| 无偿搭乘（非营运、无故意重大过失） | 减轻责任（好意同乘，1217） |
| 高空抛物难以确定侵权人 | 可能加害的使用人补偿（1254） |

## 一句话总纲

民法典七编 1260 条，以"平等自愿、诚信公平、公序良俗、绿色"六原则为魂，覆盖从出生到死亡、从交易到家事的全部民事生活；2021-01-01 施行，九部单行法同时废止——"社会生活百科全书"。
